# Assessment Tracker Demo

A sanitized Google Apps Script portfolio project demonstrating assessment data modelling, weighted outcomes and reporting.

## What it demonstrates
- Google Sheets + Apps Script architecture
- Assessment definitions and weighting
- Learner-result data modelling
- Calculated outcomes
- Dashboard/reporting logic
- Separation of data, calculation and presentation

All records are synthetic. No real learners, spreadsheet IDs, credentials or school data are included.

## Intended Sheet tabs
- `Assessments`
- `Learners`
- `Results`
- `Boundaries`
